= 了解適用於 MetroCluster IP 和 SnapMirror 作用中同步的 ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator 透過提供高可用性（HA）中繼資料的持久且受保護儲存、協助確定仲裁的同步節點健全狀況查詢功能，以及作為控制器活躍性的 ping Proxy，來支援 SnapMirror 作用中同步和 MetroCluster IP。

ONTAP Mediator 執行於第三個故障網域的 Linux 主機上，與您的 ONTAP 叢集分隔，在此為 HA 中繼資料提供持續、隔離的儲存區。ONTAP 使用此儲存區，以及 Mediator 的節點健全狀況查詢與 ping-Proxy 功能，來監控 SnapMirror 作用中同步關係與 MetroCluster IP 組態。

* ONTAP Mediator 使用節點管理 LIF 和叢集管理 LIF，透過多條備援路徑與每個叢集通訊。這使得 ONTAP 能夠區分整個站台故障和單一 InterSwitch 鏈路（ISL）故障。
* 在 SnapMirror 作用中同步中，如果叢集與其對等節點和 ONTAP 中介器皆失去連線，ONTAP 會將對等節點視為無法連線，並可自動容錯移轉至存活的複本。
* 在 MetroCluster IP 組態中，ONTAP Mediator 透過儲存有關 MetroCluster 節點的狀態資訊，並協助判斷故障期間的適當行動方案，來協助進行 Mediator 輔助的自動非計畫性切換（MAUSO）。


若要安裝或升級內部環境的 ONTAP Mediator 版本，請參閱 link:https://docs.netapp.com/us-en/ontap-mediator/index.html["ONTAP Mediator 文件"^]

有關 ONTAP Cloud Mediator（從 ONTAP 9.17.1 開始提供）的資訊，請參閱 link:../snapmirror-active-sync/index.html["SnapMirror主動同步文檔"]。
