= 在從 ONTAP 9.20.1 回復之前，請移除持續保留註冊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1 之前的版本每個 LUN 最多支援 182 個 SCSI-3 持續保留註冊。從 ONTAP 9.20.1 開始，此限制增加到 256 個。如果任何 LUN 的歷史註冊數超過 182 個，無論目前註冊數是多少，ONTAP 都會阻止回復。在從 9.20.1 回復到 9.19.1 之前，請識別並移除受影響 LUN 上的持續保留註冊。


IMPORTANT: 在叢集環境中，移除持續保留註冊可能需要在主機端重新設定。根據主機作業系統和叢集軟體的不同，您可能需要將叢集資源離線，從叢集管理中移除受影響的 LUN，並在回復後重新建立叢集存取。請在回復之前查閱叢集解決方案文件，並在測試環境中驗證恢復工作流程。

.步驟
. 檢查是否有任何 LUN 歷來的持續保留註冊次數超過 182 次：
+
[source, cli]
----
lun show -field persistent-reservation-scale-tier
----
+
persistent-reservation-scale-tier 欄位的值超過 182 表示 LUN 已分配額外的持續保留中繼資料。無論目前的註冊計數為何，這都會阻止回復。

. 對於每個受影響的 LUN，顯示目前作用中註冊計數：
+
[source, cli]
----
lun persistent-reservation show -vserver <vserver_name> -path <lun_path>
----
. 移除所有受影響 LUN 上的持續保留註冊。
+
執行回復預先檢查。如果偵測到此情況，預先檢查輸出會包含所需的特定清理命令。
