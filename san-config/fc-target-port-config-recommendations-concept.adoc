= 確定 ONTAP 系統支援的 FC 目標連接埠速度
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FC 目標連接埠可以按照與 FC 協定完全相同的方式設定並用於 FC-NVMe 協定。

為了獲得最佳效能和最高可用度，您應該使用 https://hwu.netapp.com["NetApp Hardware Universe"^]中針對您的特定 ONTAP 系統列出的建議目標連接埠組態。

每個就職 FC 連接埠和擴充介面卡連接埠均可個別設定，以支援不同的傳輸速度。支援的速度取決於您的 ONTAP 系統和 HBA。同一主機使用的所有目標連接埠都應設定為相同的速度。

最佳實務做法是，您應該為所有啟動器、交換器和目標連接埠設定相同的速率。如果連接埠和啟動器的速率不同，且無法協商出一致的速率，則無法建立工作階段。不建議使用自動協商來確定連接埠速率。自動協商可能會減慢工作階段建立速度以及中斷後的重新連線速度。

支援的速度列在每個 ONTAP 系統的 NetApp Hardware Universe 的「支援的介面卡」下。

.步驟
. 前往 link:https://hwu.netapp.com["NetApp Hardware Universe"^]。
. 選擇*產品*。
. 在 *Platforms* 下，選擇您的系統類型。
. 選擇您的特定系統，然後選擇您的 ONTAP 版本。
. 選擇 *Show Results*，然後選擇 *Supported Adapter Cards*。
+
FC 介面卡在 *Category* 下列為「Block Access (Target)」，支援的速度列在 *Supported Protocol(s)* 下。
