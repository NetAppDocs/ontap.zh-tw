= ONTAP 升級後驗證工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
升級 ONTAP 之後、您應該執行數項工作來驗證叢集就緒性。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]請驗證您的叢集。
[role="quick-margin-para"]
升級 ONTAP 後，您應該link:task_verify_cluster_after_upgrade.html["驗證叢集版本、叢集健全狀況和儲存設備健全狀況"]。如果您使用的是 MetroCluster FC 組態，則還需要驗證叢集是否已啟用自動非計劃切換。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"] 確認所有 LIF 都位於主連接埠。
[role="quick-margin-para"]
重新開機期間，某些 LIF 可能已遷移到其指派的故障轉移連接埠。升級叢集後，您必須link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["啟用並回復所有未連接到其主連接埠的 LIF"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]請確認叢集的特殊考量事項。
[role="quick-margin-para"]
如果您的叢集上存在某些組態，您可能需要 link:concept_special_configurations_post_checks.html["升級後請執行其他步驟"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"] 更新磁碟鑑定套件（DQP）。
[role="quick-margin-para"]
DQP 不會作為 ONTAP 升級的一部分進行更新。您必須link:concept_when_you_need_to_update_the_disk_qualification_package.html["更新 DQP"]在升級後。
