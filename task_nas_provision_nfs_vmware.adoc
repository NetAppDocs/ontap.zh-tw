= 使用 ONTAP 系統管理員為 VMware 資料儲存庫配置 NFS 存儲
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在使用 ONTAP tools for VMware vSphere 在基於 ONTAP 的儲存系統上為 ESXi 主機資源配置 NFS Volume 之前，請先使用適用於 ONTAP 9.7 或更新版本的 System Manager 啟用 NFS。

在 System Manager 中建立 link:task_nas_enable_linux_nfs.html["支援NFS的儲存VM"] 之後，您接著使用 ONTAP tools for VMware vSphere 來資源配置 NFS Volume 並管理資料存放區。

請務必檢查 https://imt.netapp.com/matrix/["NetApp 互通性對照表"^]以確認您目前的 ONTAP 與 ONTAP tools for VMware vSphere 版本之間的相容性。

若要使用 System Manager Classic（適用於 ONTAP 9.7 及更早版本）為 ESXi 主機設定對資料儲存的 NFS 存取，請參閱 https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["ESXi 的 NFS 組態總覽"^]

如需詳細資訊，請參閱 https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597：VMware vSphere ONTAP for VMware"^]與 https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["適用於 VMware vSphere 的 ONTAP 工具文件"^]。
