= 指定igroup的啟動器WWPN和iSCSI節點名稱
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在建立igroup時指定啟動器的iSCSI節點名稱和WWPN、也可以稍後新增。如果您選擇在建立LUN時指定啟動器iSCSI節點名稱和WWPN、則可視需要於稍後移除。

請依照 Host Utilities 文件中的說明取得 WWPN，並尋找與特定主機關聯的 iSCSI 節點名稱。對於執行 ESX 軟體的主機，請使用 ONTAP tools for VMware vSphere。
