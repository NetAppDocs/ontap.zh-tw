= 暫停 ONTAP ARP 或 ARP/AI 保護，以將工作負載事件排除在分析之外
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
如果您預期會出現異常的工作負載事件，您可以隨時暫時中止並恢復自主勒索軟體防護 (ARP 和 ARP/AI) 分析。

從 ONTAP 9.13.1 開始，您可以啟用多管理員驗證 （MAV），這樣就需要兩個或多個經過驗證的使用者系統管理員才能暫停 ARP 或 ARP/AI。

link:../multi-admin-verify/enable-disable-task.html["深入瞭解MAV"]。

.關於這項工作
在 ARP 或 ARP/AI 暫停期間，ONTAP 不會記錄新寫入的事件或動作；但是，對先前日誌的分析會在背景繼續進行。


NOTE: 請勿使用 ARP 或 ARP/AI 停用功能來暫停分析。這樣做會停用 Volume 上的保護，並且所有已學習到的工作負載行為資訊都會遺失。對於 ARP（ONTAP 9.10.1 至 9.15.1），需要重新啟動學習週期。對於 ARP/AI（ONTAP 9.16.1 及更新版本），所有累積的工作負載行為資料都會遺失。對於 SAN Volume，評估週期將從頭開始。

.步驟
您可以使用 System Manager 或 ONTAP CLI 暫停 ARP 或 ARP/AI。

[role="tabbed-block"]
====
.系統管理員
--
. 選擇 *Storage > Volumes* ，然後選擇要暫停 ARP 或 ARP/AI 的 Volume。
. 在卷概覽的「安全性」標籤中，選擇「反勒索軟體」方塊中的「暫停反勒索軟體」。
+

NOTE: 從 ONTAP 9.13.1 開始，如果您使用 MAV 來保護 ARP 或 ARP/AI 設定，暫停操作會提示您獲得一或多位其他系統管理員的核准。link:../multi-admin-verify/request-operation-task.html["必須收到所有管理員的核准"]與 MAV 核准群組相關聯，否則操作將失敗。

. 若要恢復監控，請選擇*恢復反勒索軟體*。


--
.CLI
--
. 暫停 Volume 上的 ARP 或 ARP/AI：
+
[source, cli]
----
security anti-ransomware volume pause -vserver <svm_name> -volume <vol_name>
----
. 若要繼續處理、請使用 `resume` 命令：
+
[source, cli]
----
security anti-ransomware volume resume -vserver <svm_name> -volume <vol_name>
----
+
如link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+anti-ransomware+volume+["指令參考資料ONTAP"^]需詳細 `security anti-ransomware volume`資訊，請參閱。

. 如果您使用 MAV 來保護 ARP 或 ARP/AI 設定，暫停操作會提示您獲得一位或多位其他系統管理員的核准。必須獲得與 MAV 核准群組關聯的所有系統管理員的核准，否則操作將失敗。
+
如果您使用的是 MAV 、而預期的暫停作業需要額外核准、則每位 MAV 群組核准者都會執行下列動作：

+
.. 顯示要求：
+
[source, cli]
----
security multi-admin-verify request show
----
.. 核准申請：
+
[source, cli]
----
security multi-admin-verify request approve -index[<number returned from show request>]
----
+
如果您使用的是 MAV 、而且您是 MAV 群組核准者、您可以拒絕暫停作業要求：

+
[source, cli]
----
security multi-admin-verify request veto -index[<number returned from show request>]
----
+
如link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+multi-admin-verify+request["指令參考資料ONTAP"^]需詳細 `security multi-admin-verify request`資訊，請參閱。
