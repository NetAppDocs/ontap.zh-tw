= 檢視 ONTAP 使用 FlexClone 檔案和 FlexClone LUN 的空間節省量
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在包含 FlexClone 檔案和 FlexClone LUN 的磁碟區上、檢視區塊共用所儲存的磁碟空間百分比。您可以在容量規劃中執行此動作。

.步驟
. 檢視因 FlexClone 檔案與 FlexClone LUN 而節省的空間：
+
[source, cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
如果您在啟用重複資料刪除的 FlexVol Volume 上執行此命令，您可以檢視重複資料刪除以及 FlexClone 檔案和 LUN 所節省的空間。

====
