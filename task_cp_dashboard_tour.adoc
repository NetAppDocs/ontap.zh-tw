= 從 ONTAP System Manager 儀表板檢視叢集資訊
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
System Manager 儀表板可從單一位置快速完整地檢視 ONTAP 叢集。

從 System Manager 儀表板，您可以檢視有關叢集健全狀況、容量、網路和效能的資訊，包括重要警報、儲存設備層和 Volume 的效率和容量、叢集節點的狀態和可用度、最作用中的應用程式和物件，以及效能計量。

從 ONTAP 9.19.1 開始，SVM 管理員可以使用 ONTAP System Manager 中的專用 SVM 管理員儀表板來監控和管理自己的 SVM。如需詳細資訊，請參閱link:task-svm-admin-dashboard-sm.html["使用 System Manager 管理和監控 SVM"]。

儀表板包含四個面板、如下所述：



[[view-the-cluster-health]]
== 檢視叢集健全狀況

在 ONTAP System Manager 儀表板的 *健全狀況* 區段中，您可以檢視叢集的一般資訊，例如其名稱、 ONTAP 版本和建立日期。您也可以檢視叢集節點的整體健全狀況、叢集層級的錯誤、警告、警示，以及提升叢集效能的建議修改。

從 ONTAP 9.20.1 開始，叢集或儲存設備虛擬機器（SVM）憑證到期前 30 天會顯示健全狀況警報。此警報每日更新，顯示剩餘到期天數。您可以將預設的 30 天警報臨界值修改為 0 到 90 之間的任意天數，也可以停用此功能以完全不顯示任何警報，或抑制已過期憑證的警報，同時繼續接收即將到期憑證的警報。

* 若要檢視叢集健全狀況資訊，請選取儀表板上 *健全狀況* 旁邊的 image:icon_arrow.gif["箭頭圖示"]。
* 若要修改憑證到期設定，請選取警示，然後選取 *憑證設定*。




[[view-the-cluster-capacity]]
== 檢視叢集容量

在 ONTAP System Manager 儀表板的 *容量* 部分，您可以檢視叢集的儲存空間。您可以檢視已使用邏輯空間總量、已使用實體空間總量和可用磁碟空間。

您可以選擇註冊 ActiveIQ 以檢視歷史叢集資料。

在儀表板上選擇 *容量* 旁的 image:icon_arrow.gif["箭頭圖示"]，以檢視叢集容量資訊，包括與叢集相關的層級總覽，例如總空間、已使用空間和可用空間。此外，也會顯示處理量、IOPS 和延遲的詳細資訊。link:./concepts/capacity-measurements.html["了解 ONTAP 如何報告已使用的儲存設備"]。

您可以選擇使用容量檢視來新增本機層或雲端層。如需詳細資訊、請 link:task_admin_monitor_capacity_in_sm.html["檢視叢集的容量"]參閱。



[[view-the-cluster-network]]
== 檢視叢集網路

在 ONTAP System Manager 儀表板的 *網路* 部分中，您可以檢視網路中的實體連接埠、網路介面和儲存 VM。

「網路」檢視會顯示連線至網路的用戶端類型。每個網路連線的用戶端都會以數字表示（例如「 NVMe / FC 16 」）。選取數字以檢視每個網路元件的特定詳細資料。

在儀表板上選擇 *網路* 旁的 image:icon_arrow.gif["箭頭圖示"]，即可檢視包含網路上的連接埠、網路介面、儲存設備虛擬機器和主機的廣泛全頁網路檢視。



[[view-the-cluster-performance]]
== 檢視叢集效能

在 ONTAP System Manager 儀表板的 *效能* 部分，您可以檢視效能統計資料，以協助監控 ONTAP 叢集的健全狀況和效率。這些統計資料包括關鍵的叢集效能指標，例如延遲、處理量和 IOPS，並以圖表的形式呈現。

「效能」檢視會依日期、小時、週或年、以不同的時間間隔顯示效能統計資料。您可以使用各種圖表快速分析叢集效能、並識別可能需要最佳化的特性。這項快速分析可協助您決定如何新增或移動工作負載。您也可以查看尖峰使用時間、以規劃可能的變更。

效能檢視會顯示與延遲、處理量和 IOPS 相關的整體效能指標。

從 9.15.1 開始、效能檢視會增強、以顯示與延遲、處理量和 IOPS 相關的讀取、寫入、其他和總效能指標圖表。其他度量包括任何非讀取或寫入的作業。

效能值每3秒重新整理一次、效能圖表每15秒重新整理一次。如果無法取得叢集效能的相關資訊、將不會顯示圖表。

在儀表板上選擇 *效能* 旁的 image:icon-expansion-arrows.png["擴充圖示"]，即可查看按小時、天、週、月和年劃分的效能計量全頁檢視。您也可以將效能計量報告下載至本機系統。
