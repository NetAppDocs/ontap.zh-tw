= 在 System Manager 中設定 ONTAP 使用者密碼過期提醒
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從 ONTAP 9.20.1 開始，如果與使用者帳戶關聯的角色已設定密碼過期警示，使用者在登入 System Manager 後，會立即在頁面頂端收到橫幅警示，此警示會在密碼過期前 14 天開始發出。每次使用者登入時，警示都會更新，以顯示密碼過期前剩餘的天數。您可以在新增或編輯系統管理員角色時設定過期警示。

.步驟
. 選擇*叢集>設定*。
. 選取 *使用者與角色* 旁邊的 image:icon_arrow.gif["箭頭圖示"]。
. 新增或編輯使用者角色時，設定密碼過期提醒。
+
** 若要在新增使用者角色時進行設定，請在 *角色* 下，選取 image:icon_add.gif["新增圖示"]。輸入角色名稱，然後選取密碼過期期限和密碼過期警示。
** 若要在編輯使用者角色時進行設定，請在 *角色* 下，選取使用者角色。選取 *編輯* ，然後選取密碼過期期間。
** 選取*「Add*」。




.結果
使用者登入 System Manager 後，會立即收到頁面頂端的橫幅警示，從密碼過期前的選定天數開始顯示。每次使用者登入時，警示都會更新，以顯示密碼過期前剩餘的天數。
