= 變更 ONTAP 管理員密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
首次登入後，您應該立即更改初始 ONTAP 系統管理員密碼，之後也應定期更改，以協助保持叢集安全。

從 ONTAP 9.20.1 開始，如果您的使用者帳戶設定了密碼過期警示，System Manager 會在密碼過期前 14 天開始顯示橫幅警示。每次登入時，警示都會更新以顯示剩餘天數。

.關於這項工作
新密碼必須遵守下列規則：

* 它不能包含使用者名稱
* 長度必須至少八個字元
* 它必須包含至少一個字母和一個數字
* 不能與最後六個密碼相同



NOTE: 您可以使用 `security login role config modify`命令來修改與指定角色相關聯之帳戶的密碼規則。

.開始之前
* 您必須是叢集或SVM管理員、才能變更自己的密碼。
* 您必須是叢集管理員、才能變更其他管理員的密碼。


.步驟
使用 System Manager 或 ONTAP 命令列介面（CLI）變更密碼。

[role="tabbed-block"]
====
.系統管理員
--
. 在System Manager中、選取*叢集>設定*。
. 在 *使用者與角色* 下，選取 *使用者*。
. 選取需要變更密碼的使用者帳戶旁邊的 image:icon_kabob.gif["選單"]，然後選取 *變更密碼*。
. 請輸入新密碼。
. 重新輸入新密碼以進行確認，然後選擇 *儲存*。


--
.CLI
--
如果您是 SVM 系統管理員，可以使用  `security login password` 命令變更自己的密碼。如果您是叢集管理員，可以使用  `security login password` 命令變更任何系統管理員的密碼。

. 變更管理員密碼： `security login password -vserver _svm_name_ -username _user_name_`
+
下列命令會變更 SVM `vs1.example.com` 的系統管理員 `admin1`密碼。系統會提示您輸入目前的密碼，然後輸入並再次輸入新密碼。

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----
