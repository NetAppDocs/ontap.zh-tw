= 重設並重新探索信任的 ONTAP SMB 網域
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以強制重新探索所有信任的網域。當受信任的網域伺服器沒有適當回應或信任關係變更時、此功能就很有用。只會探索主網域具有雙向信任的網域、亦即包含CIFS伺服器電腦帳戶的網域。

從 ONTAP 9.13.1 開始，當 ONTAP 重新探索受信任網域時，它也會對這些受信任網域執行站台探索。ONTAP 使用探索到的站台資訊來進行受信任網域的網域控制器查閱。這有助於確保 DNS SRV 查閱使用正確的受信任網域網域控制器站台資訊。如果受信任網域的站台探索失敗， ONTAP 將使用 SMB 伺服器的預設站台。

.步驟
. 使用重設及重新探索信任的網域 `vserver cifs domain trusts rediscover` 命令。
+
`vserver cifs domain trusts rediscover -vserver vs1`
