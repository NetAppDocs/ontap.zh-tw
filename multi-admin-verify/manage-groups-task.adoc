= 管理 MAV 的 ONTAP 管理員核准群組
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在啟用多管理員驗證（MAV）之前、您必須先建立管理員核准群組、其中包含一或多位系統管理員、以便獲得核准或否決權限。啟用多管理員驗證之後、任何對核准群組成員資格的修改都必須取得現有合格管理員的核准。

.關於這項工作
您可以將現有的系統管理員新增至MAV群組、或建立新的系統管理員。

MAV功能可執行現有的角色型存取控制（RBAC）設定。潛在的MAV系統管理員必須擁有足夠的權限、才能執行受保護的作業、才能將其新增至MAV系統管理員群組。 link:../authentication/create-svm-user-accounts-task.html["深入瞭解RBAC。"]

您可以設定MAV來警示MAV系統管理員核准要求已擱置。若要這麼做、您必須設定電子郵件通知、尤其是 `Mail From` 和 `Mail Server` 參數 -- 或者您可以清除這些參數以停用通知。沒有電子郵件警示、MAV管理員必須手動檢查核准佇列。

從ONTAP 9.15.1 開始，您可以將 Active Directory (AD) 使用者設定為 MAV 管理員。  AD 使用者必須是link:../authentication/grant-access-active-directory-users-groups-task.html["配置為ONTAP管理員"]。

從 ONTAP 9.20.1 開始，核准群組也可以包含身分供應商（IdP）、Active Directory（AD）或 LDAP（nsswitch）群組。支援的群組類型包括 Entra ID（以前稱為 Azure AD）、ADFS、AD 網域群組和 LDAP 群組。

使用者在身分供應商中的群組成員身分變更將在使用者下次成功登入後生效。無需重新設定 MAV。


NOTE: 在將 IdP、AD 或 LDAP 群組新增至 MAV 核准群組之前，該群組必須已設定登入存取，且必須在  `security login group` 表格中註冊並具有角色對應。請參閱下列程序。



[[system-manager-procedure]]
== System Manager程序

如果您想第一次建立MAV核准群組、請參閱的系統管理員程序 link:enable-disable-task.html#system-manager-procedure["啟用多管理員驗證。"]

若要修改現有的核准群組或建立其他核准群組：

. 識別要接收多管理員驗證的系統管理員。
+
.. 選擇 *叢集 > 設定。*
.. 選取 *使用者、群組和角色* 旁邊的 image:icon_arrow.gif["箭頭圖示"]。
.. 在 *使用者* 下選取 image:icon_add.gif["新增圖示"]。
.. 視需要修改名單。
+
如需詳細資訊、請參閱 link:../task_security_administrator_access.html["控制系統管理員存取權。"]



. 從 ONTAP 9.20.1 開始，如果您想要新增 IdP、AD 或 LDAP 群組作為 MAV 核准者，請先註冊該群組，以便在 MAV 組態中參照它。
+
.. 在 *群組* 下，選取 image:icon_add.gif["新增圖示"] 以新增群組。
+
輸入群組名稱。UUID 欄位僅對 Microsoft Entra 群組是必要的；其他身分提供者使用群組名稱。

.. 在 *群組到角色對應* 下，選取 image:icon_add.gif["新增圖示"]，選取群組，並指派具有足夠權限的角色以核准 MAV 要求。


. 建立或修改MAV核准群組：
+
.. 選擇 *叢集 > 設定。*
.. 選取 *安全性* 區段中 *多重管理員核准* 旁邊的 image:icon_arrow.gif["箭頭圖示"]。（如果尚未設定 MAV，您將會看到 image:icon_gear.gif["動作圖示"] 圖示。）
+
*** 名稱：輸入群組名稱。
*** 審核者（使用者）：從使用者清單中選擇個別審核者。
*** 審核者（群組）：從 ONTAP 9.20.1 開始，可選擇一個或多個已註冊的 IdP、AD 或 LDAP 群組。
*** 電子郵件地址：輸入電子郵件地址。
*** 預設群組：選取群組。






啟用MAV後、必須取得MAV核准才能編輯現有的組態。



[[cli-procedure]]
== CLI程序

. 確認已為設定值 `Mail From` 和 `Mail Server` 參數。輸入：
+
`event config show`

+
顯示器應類似於下列內容：

+
[listing]
----
cluster01::> event config show
                           Mail From:  admin@localhost
                         Mail Server:  localhost
                           Proxy URL:  -
                          Proxy User:  -
 Publish/Subscribe Messaging Enabled:  true
----
+
若要設定這些參數、請輸入：

+
`event config modify -mail-from _email_address_ -mail-server _server_name_`

+
深入瞭解 `event config show`及 `event config modify` link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=event+config["指令參考資料ONTAP"^]。

. 確定參與多重系統管理員驗證的系統管理員。
+
[cols="50,50"]
|===
| 如果您想… | 輸入此命令 


| 顯示目前的系統管理員  a| 
`security login show`



| 修改目前系統管理員的認證資料  a| 
`security login modify _<parameters>_`



| 建立新的系統管理員帳戶  a| 
`security login create -user-or-group-name _admin_name_ -application ssh -authentication-method password`

|===
+
深入瞭解 `security login show`， `security login modify`和 `security login create` link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+login["指令參考資料ONTAP"^]。

. 從 ONTAP 9.20.1 開始，如果您想要將 IdP、AD 或 LDAP 群組新增為 MAV 審核人，請確認群組已設定登入存取，然後將其註冊至 MAV。
+
如果該群組尚未設定登入存取，請輸入：

+
`security login create -user-or-group-name _group_name_ -application http|ssh -authentication-method domain|nsswitch|saml|oauth2 -role _role_`

+
然後註冊該群組，以便在 MAV 組態中參照它，並將其對應至一個角色：

+
`security login group create -vserver _svm_name_ -name _group_name_ [-uuid _uuid_]`

+
`security login group role-mapping create -group-id _group_id_ -role _role_`

+
此 `-uuid`參數僅為 Microsoft Entra ID 群組所需。AD 網域、ADFS/SAML 和 LDAP （nsswitch） 群組僅透過名稱進行識別。

+
*範例：* 以下命令將 AD 群組 `mydomain\mav_approvers`註冊至 MAV，並將其對應至 `admin`角色。

+
[listing]
----
cluster-1::> security login group create -vserver cluster-1 -name mydomain\mav_approvers
cluster-1::> security login group show -vserver cluster-1

     Vserver: cluster-1
  Group Name: mydomain\mav_approvers
    Group ID: 1
  Group UUID: -
     Comment: -

cluster-1::> security login group role-mapping create -group-id 1 -role admin
----
+
深入瞭解 `security login group create`和 `security login group role-mapping create`，請參閱link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+login+group["指令參考資料ONTAP"^]。

. 建立MAV核准群組：
+
`security multi-admin-verify approval-group create [ -vserver _svm_name_] -name _group_name_ [-approvers _approver1_[,_approver2_…]] [-groups _group1_[,_group2_…]] [[-email _address1_], _address1_...]`

+
** `-vserver` - 此版本僅支援管理 SVM 。
** `-name` - MAV 群組名稱、最多 64 個字元。
** `-approvers` - 一個或多個個別核准者的清單。對於 AD 使用者，請使用格式 `domain\user`。例如， `mydomain\pavan`。
** `-groups` - 要包含在核准群組中的一個或多個 IdP、AD 或 LDAP 群組清單。每個群組必須已在 `security login group`表格中註冊，並具有角色對應。
** `-email` ：一或多個電子郵件地址、在建立、核准、遭否決或執行要求時收到通知。
+
*範例：* 下列命令建立一個包含兩個獨立審核者和一個 Entra ID 群組的 MAV 群組。

+
[listing]
----
cluster-1::> security multi-admin-verify approval-group create -name mav-grp1 -approvers pavan,julia -groups entra-group-mav-approvers -email pavan@myfirm.com,julia@myfirm.com
----


. 驗證群組建立與成員資格：
+
`security multi-admin-verify approval-group show`

+
*範例：*

+
[listing]
----
cluster-1::> security multi-admin-verify approval-group show
Vserver  Name        Approvers        Approver Groups                  Email
-------  ---------------- ------------------  ------------------------------- ------------------------------------------------------------
svm-1    mav-grp1   pavan,julia      entra-group-mav-approvers        pavan@myfirm.com,julia@myfirm.com
----


使用這些命令來修改初始MAV群組組組態。

*附註：*所有項目都需要MAV系統管理員核准才能執行。

[cols="50,50"]
|===
| 如果您想… | 輸入此命令 


| 修改群組特性或修改現有的成員資訊  a| 
`security multi-admin-verify approval-group modify [-vserver _svm_name_] -name _group_name_ [-approvers _approver1_[,_approver2_…]] [-groups _group1_[,_group2_…]] [[-email _address1_], _address1_...]`



| 新增或移除成員  a| 
`security multi-admin-verify approval-group replace [-vserver _svm_name_] -name _group_name_ [-approvers-to-add _approver1_[,_approver2_…]][-approvers-to-remove _approver1_[,_approver2_…]] [-groups-to-add _group1_[,_group2_…]][-groups-to-remove _group1_[,_group2_…]]`



| 刪除群組  a| 
`security multi-admin-verify approval-group delete [-vserver _svm_name_] -name _group_name_`

|===
