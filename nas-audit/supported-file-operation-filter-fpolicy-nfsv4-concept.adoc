= ONTAP 中支援 NFSv4 的 FPolicy 檔案操作和過濾器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
設定FPolicy事件時、您必須注意、監控NFSv4檔案存取作業時、僅支援特定的檔案作業和篩選器組合。

從 ONTAP 9.15.1 開始、 FPolicy 支援 NFSv4.1 傳輸協定。

從 ONTAP 9.19.1 開始，管理員可以在 SVM 層級控制 NFSv4.2 的可用性，使用 System Manager、CLI 或 REST API 為個別儲存 VM 啟用或停用該傳輸協定。

從 ONTAP 9.20.1 開始，FPolicy 支援監控 NFSv4.2 檔案存取事件，包括擴充屬性（xattr）寫入的新檔案作業，以及標記 NFS 活動的安全性標籤篩選器。進一步瞭解 link:../nfs-admin/enable-disable-nfs-task.html["為 ONTAP SVM 啟用或停用 NFS"]。


NOTE: 安全標籤過濾器 (`setattr_with_security_label_change` 和  `getattr_with_security_label_read`）需要在 SVM 上啟用 NFSv4.2 安全性標籤（帶標籤的 NFS）。進一步瞭解 link:../nfs-admin/enable-nfsv42-security-labels-task.html["啟用 NFSv4.2 安全性標籤"]。 `getxattr` 和  `listxattrs` 是唯讀作業，不受 FPolicy 監控。
